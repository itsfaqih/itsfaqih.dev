# Personal Website Agent Rules

- Run the personal website development server with `npm run dev`, never `bun run dev`.
- Use `npm run ...` for website scripts such as build, lint, test, and Storybook. Bun may be used for dependency installation or update commands, but not to launch the development server.
- Reuse the existing local server on port 5173 when possible; do not stop it unless necessary or explicitly requested.
- For UI checks, use `browser_exec` with the pre-authorized agent Chrome profile `~/.hermes/chrome-debug` via CDP `http://127.0.0.1:9223`; use distinct sessions for concurrent workers. No permission prompt is needed for this isolated browser. Never use the user's regular Chrome or handle credentials.
