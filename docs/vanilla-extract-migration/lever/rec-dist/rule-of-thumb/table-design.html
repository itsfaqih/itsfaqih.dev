Table Design

Line up what people compare, and never leave a table blank.

Right-align numbers, pin actions to a fixed last column, and give every blank a next step.

RAGGED→ALIGNED

Design tables for scanning

Make each column easy to run an eye down, since people scan for one value.

Right-align numbers

People compare numbers by their last digits. Use tabular figures so every digit is the same width, and add thousands separators. Watch the right edge.

Give every state a next step

A table is often loading, empty, failed or showing no matches. Draw each one. Use skeleton rows to keep the shape while it loads, and say why and what to do next in every blank. Pick a state, search, then press the buttons.

Put actions in a fixed last column

Give the column a fixed width and right-align it, so Edit sits in the same place on every row. Use icon buttons to save room, and name each one with a tooltip. Hover the rows, then delete one.

Skip the pager for one page

With one page, a pager is a row of dead arrows. Under an empty table, it reads Page 1 of 0. Filter the list and watch both.

Keep the page in the URL

With ?page=2 in the address, a reload, the Back button and a shared link all land where you were. Reload each.

TL;DR

  1. A column of numbersRight-align it, with tabular figures and separators
  2. Money in a finance viewUse a monospace face
  3. Rows still loadingDraw skeleton rows at the real row height
  4. Empty, failed or no matchSay which and give one next step: Add, Retry, Clear search
  5. Row actionsPut icon buttons with tooltips in a fixed last column
  6. One page, or noneSkip the pager
  7. The current pagePut it in the URL as ?page=2
